# Independent checks

Use when a task requires checking several independent candidates, such as services, listings, or files.

1. State the decision criteria and identify which checks have no dependency on one another.
2. Run independent read-only checks concurrently when the available tools allow it. Keep each result associated with its source.
3. Compare verified current results, then perform dependent steps in order.
4. Save reusable navigation or API procedures in a reviewed local note. Recheck changing facts such as availability, prices, and requirements for every task.
5. Before placing an order, booking, sending a message, or making another external commitment, present the concrete choice for approval.

This skill guides tool use; it does not add a browser, booking API, or access to external accounts.
